Monite (Monite GmbH) is an embedded finance API platform that lets neobanks and B2B SaaS platforms add invoicing, accounts payable automation, payments and related financial workflows to their own products, with a fully embeddable SDK and UI components. Its REST API (api.monite.com, with a sandbox at api.sandbox.monite.com) is documented at docs.monite.com, and the company publishes a public API style guide with Spectral rules on GitHub.

**Areas:** Company · Embedded Finance · Invoicing · Accounts Payable · Payments · B2B · Fintech · Software-as-a-Service

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Monite: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
